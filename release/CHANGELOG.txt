360AI 1.6 - native offline keyword assistant
==========================================

- Press X on the model list to open 360 Assistant with no GGUF weights.
- Calculations, operator precedence, functions, percentages and ans.
- Unit conversion and follow-up values across five unit dimensions.
- Eight session timers, relative reminders, named alerts and timer history.
- Saved notebook/name with validated JSON, atomic writes and backup recovery.
- Status, console clock, model list, presets, export and model navigation.
- Keyword/phrase boundaries, polite prefixes, follow-up slots, negation,
  confirmations, conservative typo suggestions and clear fallback responses.
- Optional text-only FAQ rules; bounded input, notes, rules and scrollback.
- Fallback keyboard now includes parentheses, powers and apostrophes.
- Assistant chat requires no inference or network. Existing GGUF mode remains.

Text input/output only: no microphone, speech recognition or spoken replies.
Timers need the app to remain running and do not survive restarting it.
Personal notes/settings are not bundled. Full model package remains available.
Native functional checks and Xbox SDK build pass; physical controller/UI,
alert banner and drive persistence require Xbox validation. See ASSISTANT.txt.

360AI 1.5 - smaller models and native speed defaults
===================================================

- Bundled TinyStories 15M Q4_0 (19 MB) and 260K F32 (1.2 MB) story toys.
- Clearly labeled very limited completion models; plain-text prompts, not INST.
- Existing SmolLM2 and Gemma weights are unchanged. Four models in one USB ZIP.
- New installs: 256 context / 48 reply tokens; SmolLM2 highlighted for chat.
- Upgrades preserve saved settings. Select Quick to shorten old budgets and
  reset forced GPU/HDD streaming to Auto.
- Q8 paired-row CPU candidate shares inputs. A per-width numerical/timing
  check selects it only with >=10% measured improvement, otherwise single rows.
- Xenon F32 rows swap bytes in VMX registers, avoiding scratch row conversion.
- Float vector dots use independent accumulators; context limits are enforced.

VALIDATION
Xbox SDK build, native inference/tokenizer/settings/matrix checks and all eight
protocol/tokenizer/package groups pass. Real models generate on the host;
RAM and streamed output/KV parity and conversation cache reuse are verified.
Physical-console VMX speed and controller behavior still need testing. Initial
Q8 calibration adds one-time work. TinyStories is not a chat replacement;
260K may be nonsense, and 15M has a 128-token context. No Xbox speed multiplier
is claimed. Use Auto/RAM for small models; HDD streaming can be extremely slow.

360AI 1.4 - native reply controls and cancellation
================================================

- Quick, Balanced and Creative presets in the Xbox Settings menu.
- Quick uses 256 context/48 reply tokens; Balanced 512/128; Creative 512/192.
- Console top-p probability cutoff and recent reply repetition penalty.
- New sampling preferences persist; existing settings keep old behavior.
- Layer progress during prompt processing and reply generation.
- Y cancellation checks between attention, feed-forward and layer work.
- Partial replies survive cancellation; interrupted cache entries are not reused.

VALIDATION
Xbox SDK build, native sampling/preset/settings/cancellation/recovery checks
and all eight protocol/tokenizer/package groups pass. Both bundled models
keep previous greedy sample text with controls disabled; RAM and streamed
outputs and complete KV caches match. Hardware menus, sampling quality and
performance need console testing. Cancellation waits for the current matrix,
disk read or GPU operation. Quick limits reply/context budgets; no Xbox
tokens-per-second gain is claimed. Large HDD models remain slow.

360AI 1.1.1 - performance patch
================================

- Direct Q4/Q5/Q8 CPU/VMX dot products; faster grouped Q4_K/Q5_K decoding.
- Assigned matrix workers to separate Xenon physical cores, replacing
  inherited single-hardware-thread execution and polling waits.
- Compute Auto compares real-weight CPU/GPU timing and numerical parity.
- Weight storage Auto chooses RAM when weights and working memory fit.
- Matching conversation prefixes reuse KV data instead of full reprocessing.
- Single-row disk reads no longer fetch the full 8 MB cache.
- Prompt progress, elapsed time, actual decode speed and performance logs.
- Console reply token limit is adjustable, default 128 (previously up to 512).

VALIDATION
Xbox SDK build and eight protocol/tokenizer/package groups passed. Native
checks cover kernels, prefix edits, reload/clear, cancellation and trimming.
Real-model cache tests match output tokens and valid KV entries exactly.
Same host prompt/output: SmolLM2 7.10 -> 2.14 seconds; Gemma 5.49 -> 1.87.
These are Windows CPU measurements. Xbox VMX/core/backend performance
remains a physical-console validation task. Large HDD models stay slow.

360AI 1.1
==========

- Bundled SmolLM2 135M Instruct Q8_0 alongside Gemma 3 270M Instruct Q8_0.
- Added SmolLM tokenization, including its incomplete byte vocabulary.
- HDD/USB streaming loads matrix weights through a fixed 8 MB cache.
  Tokenizer, working buffers and KV cache still require console RAM.
- Added 64-bit file access and standard split-GGUF loading/validation.
- Added optional, checksum-verified Qwen2.5 0.5B, 1.5B and 7B downloads.
  Interrupted downloads resume. Larger models remain experimental.
- Model browser shows model size and recommended free HDD/USB space.
  Qwen 7B needs 5 GB free for its two model shards.
- Storage read errors stop generation and appear in UI, health, API and MCP.
- Default context is now 512 tokens.
- One complete USB ZIP includes both models, model guide, downloader,
  required licenses/notices and the rebuilt 360AI.xex.

VALIDATION
Xbox 360 SDK build passed. Native checks and eight protocol/tokenizer/
package test groups passed, including 780 tokenizer reference cases.
Real Gemma and SmolLM2 host runs produced identical tokens and KV caches
in RAM and streamed modes. Cache-boundary, disk-failure and split-model
tests passed. Physical-console HDD performance remains unverified.
The GPU path is unchanged; no GPU speed improvement is claimed.

KNOWN LIMITS
Disk streaming does not replace RAM for attention, tokenizer or UI data.
Qwen 1.5B and 7B are experimental and not console-benchmarked; large
models can be extremely slow. Start with context 256-512. See MODELS.txt.


360AI 1.0
==========

- Faster top-k candidate selection and softmax limited to selected tokens.
- Removed an unused model forward pass at the response token limit or stop.
- Warning-level logging by default to reduce per-layer USB log writes.
- Release packaging produces only the complete USB ZIP and prints its checksum.
- README discloses AI assistance with development, debugging and documentation.

- Packaged 360AI.xex for copying directly into a USB/HDD app folder.
- Updated the existing 1.0 USB ZIP to include Gemma 3 270M Instruct Q8_0
  weights, pinned source/checksum, and required terms and notices.
- Gemma 2/3 plus dense Llama and Qwen2/2.5 GGUF execution paths.
- Experimental Xenos pixel-shader matrix calculations with CPU fallback.
- Tile-aligned R32F GPU resolve and untiled CPU readback; pixel-center sampling.
- GPU startup diagnostics include actual/expected values if validation fails.
- Corrected packed quantized-weight layouts and multi-block decoding.
- OpenAI-compatible completions/chat endpoints with streaming.
- Xbox insecure-LAN socket privilege and per-socket plaintext configuration.
- Health endpoint and local browser-client CORS/preflight support.
- MCP tools endpoint; optional PC bridge for external MCP servers.
- Original project credited to Canyons and contributors.

VALIDATION
Built and packaged with the Xbox 360 SDK. Native inference, weight
decoding, tokenizer, HTTP/MCP and executable privilege tests pass.
The bundled full GGUF also loads and generates text with the host build
of this engine. Source and archived model SHA-256 checksums are verified.
GPU performance and the corrected GPU path remain to be verified on
physical Xbox 360 hardware. No GPU speed improvement is claimed.

KNOWN LIMITS
MoE, Qwen3, vision/audio, arbitrary chat
templates and unsupported RoPE scaling are not implemented. Architecture
support does not mean every model fits console RAM. Consult the project
README for the detailed compatibility list.
