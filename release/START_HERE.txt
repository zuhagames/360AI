360AI 2.8 - Xbox 360 USB package
================================

INSTALL
Launch 360AI.xex to open Home. Select Assistant for immediate predefined
replies, Notes/Timers for controller tools, or Models for GGUF chat.
On Home, X opens input and Y opens Quick tools. Say hello or type help.
360 Assistant handles calculations, conversions, notes, session timers and
taught answers. Search/edit notes, pause/resume timers and undo data changes.
This mode uses text, not voice. It works even with no GGUF files installed.
Home > Y Quick tools > Saved answers lets you add/edit your own instant replies.
X: new phrase then answer. A: edit. Y: delete confirmation. START: undo.
In My answers, click right stick for a non-executing saved-text preview.
250 starter questions/replies are included, separate from personal slots.
Click left stick in Saved answers for Starter/My; D-pad Left/Right changes
category. A customizes a starter. The full question is shown with the reply.
START in Starter view finds keywords; Y clears the filter. Right-stick click
asks the selected question, and B returns to the results. You can also type
find answers timer in Assistant. My answers keeps START undo and text preview.
BACK in Starter view opens topics and Recently asked (last 12 browser questions).
X on Recently asked in the topic picker clears recents for this app session.
Y clears a topic/search filter. B from the topic picker keeps your current list.
Cancelling a keyboard keeps existing answers. Wait for Saved after an edit.

1. Extract the ZIP on your PC.
2. Copy the entire 360AI folder to your USB drive.
3. Gemma 3 270M, SmolLM2 135M and two TinyStories toys are included.
   No separate download is needed for these models.
4. Safely eject the USB, connect it to your modded Xbox 360, and open
   the 360AI folder with your existing XEX launcher (Aurora/XEXMenu).
5. For model chat, open Models, select an included GGUF and choose Load model.
   Leave Compute backend and Weight storage on Auto. Auto selects RAM
   when the model and working memory fit, and benchmarks CPU/GPU.
   SmolLM2 135M is a good starting point for responsive local chat.

Example USB layout:
  USB:/360AI/360AI.xex
  USB:/360AI/360AI-updater.xex
  USB:/360AI/gemma-3-270m-it-Q8_0.gguf
  USB:/360AI/SmolLM2-135M-Instruct-Q8_0.gguf
  USB:/360AI/stories15M-q4_0.gguf
  USB:/360AI/stories260K.gguf
  USB:/360AI/START_HERE.txt
  USB:/360AI/CHANGELOG.txt
  USB:/360AI/CREDITS.txt
  USB:/360AI/ASSISTANT.txt
  USB:/360AI/assistant-rules.example.json

The folder can also be copied to your Xbox HDD. Keep the GGUF beside
the executable. No SDK, Visual Studio, Node.js or separate shader files
are needed on the console. The app does not install or replace a dashboard.

BUNDLED MODELS
The full Gemma 3 270M Instruct Q8_0 GGUF is included (about 292 MB).
Read NOTICE, GEMMA_TERMS.txt and GEMMA_POLICY.txt for its terms, and
MODEL_INFO.txt for its source and checksum. No account or network is
needed for local console chat once this ZIP is downloaded.
SmolLM2 135M Instruct Q8_0 is also included (about 145 MB). It uses less
weight memory. See SMOLLM2_INFO.txt and APACHE-2.0.txt for its source/license.
TinyStories 15M Q4_0 (19 MB) and 260K F32 (1.2 MB) are much smaller toys.
They continue English story openings: try Once upon a time. They do not
follow instructions or answer questions reliably. 260K may produce nonsense;
15M has only 128 tokens of context, including prompt and reply work.
See TINYSTORIES_INFO.txt and TINYSTORIES_LICENSE.txt (MIT).

Read MODELS.txt for optional Qwen models and their HDD space requirements.
Download-Models.ps1 runs on your Windows PC and verifies pinned checksums.
For larger models choose Weight storage: HDD/USB stream. Matrix weights stay
on disk with an 8 MB cache; tokenizer/scratch/KV buffers still use RAM.
Keep all split GGUF files together and select the first shard. The browser
shows their total storage requirement. Large models can be extremely slow.
Start with context 256-512. This app requires unsigned-XEX support.

PERFORMANCE
For shorter console replies, select Reply preset in Settings and press A
to cycle Quick, Balanced and Creative. Quick uses context 256 and a
48-token reply cap. Balanced uses 512/128; Creative uses 512/192.
Presets set compute/storage to Auto and change sampling controls.
Manual changes display Custom. Your server/chat toggles stay as selected.

Top-P (0.05-1.00) keeps a probability-based subset of top-k candidates.
Repeat penalty (1.00-1.50) discourages tokens in the last 64 generated
reply tokens, once per distinct token. A value of 1 disables each control.
Both are remembered in 360AI.json; existing settings retain old defaults.
These new sampling controls apply to console chat.

Compute backend Auto uses a short CPU/GPU numerical and timing comparison.
GPU math uses Xenos pixel shaders; Auto keeps it only when the sample is
correct and at least 20% faster. Forced GPU remains experimental.
The chat footer and 360AI.log show which backend/storage were selected.
Matching conversation history is reused. Prompt progress and elapsed time
are displayed while processing; tokens/second measures generation itself.
New installs default to 256 context and 48 reply tokens. Saved preferences
are preserved; select Quick to update older settings in one step.
Q8 CPU kernels compare single/paired rows once per input width and keep the
paired path only if it agrees numerically and measures at least 10% faster.
The first use includes this calibration. TinyStories 260K uses a direct F32
VMX matrix path with endian conversion in registers. Xbox speed needs testing.
The chat screen also shows layer progress during prompt and reply work.
Y cancellation is checked between attention, feed-forward and layer work.
The current matrix, disk read or GPU operation still has to finish.
Cancelled replies keep completed text; interrupted tokens are not reused.
Xbox speed and full GPU correctness still need physical-console testing.

NEW CHAT CONTROLS AND SAVED SETTINGS
UP/DOWN: scroll one line. LB/RB: scroll a page. Click right stick: latest.
Scrolling up pauses automatic following, including while a reply streams.
Scroll to the bottom or click right stick to follow new text again.
X: start a new conversation without reloading the model (when idle).
START: save the current conversation to 360AI-chat.txt (when idle).
Y: Quick tools in Assistant, or stop a running model reply.
B: Home from Assistant; model list from model chat; Home from model list.
Notes/Timers have dedicated controller controls; see ASSISTANT.txt.
Assistant data saves in the background. Wait for Saved before closing after
an edit. Not saved means the data is still in memory; check drive write access.
Saving a conversation replaces the previous export; nothing is exported
automatically. The model and weight files stay loaded for a new chat.
If an API request is running, new chat reports busy instead of waiting.

Settings are remembered in 360AI.json beside the executable, including
context, sampling, reply limit, logging and chat/server/backend/storage.
The model browser remembers your last selection when the file is present.
It highlights that model after restart; it does not load automatically.
A previous valid copy is kept in 360AI.json.bak for recovery. These files
are not bundled in updates. Remove both files to restore defaults.
The app folder must be writable to save settings and conversations.

Long conversations keep complete recent turns in the model context.
Older messages remain in the transcript for scrolling and export. Very long
messages are shortened at UTF-8 character boundaries while preserving the
model template; a notice explains when history or input was shortened.
The original message remains in the transcript, including exported chats.

OPTIONAL OPENAI / MCP SERVER
Turn OpenAI / MCP server ON before loading the model. Use the IP and
port displayed on the console; the default port is 80, then 8080.
Open http://CONSOLE-IP:PORT/health to check connectivity.
OpenAI client base URL: http://CONSOLE-IP:PORT/v1
Generation endpoints require POST with JSON, not browser navigation.
The server is for your private LAN; it has no authentication.

Requests support temperature, top_k, max_tokens/max_completion_tokens,
stop strings and streaming usage. Stop strings can span multiple tokens.
Responses include token usage and timings, and distinguish stop/length.
For streaming usage add stream_options: {"include_usage": true}.
Developer-role text messages map to system messages for local templates.

External MCP stdio/HTTPS servers use the bridge source from the project's
GitHub repository on a PC. See docs/TECHNICAL.md in the repository for setup.
Local console chat does not need the bridge or any PC software.

GITHUB UPDATES
On Home press START for Updates. Checks run in the background on launch.
Press A to download a small app update, then A to restart and install it.
Keep 360AI-updater.xex beside the app, 32 MB free, and the console clock correct.
Models, notes and settings stay in place. Read UPDATES.txt for recovery/help.
Install this complete ZIP once when upgrading from 2.0 or earlier.

HUGGING FACE MODEL LIBRARY
Open Models and press Y, or type find models in Assistant.
Search public GGUF text-generation models and inspect their individual files.
Under 200 MB: Comfortable (green). 200-300 MB: Tight (yellow).
300 MB or more: Disk stream (orange). These are file-size estimates.
Use Y for parameter limits, LB for candidate/all families, RB for the next page.
START cycles family presets; D-pad Left opens a cached previous page.
Searches/filters are remembered. Downloads show speed and estimated time left.
Local Models: LB switches smallest-first/name sorting and keeps your selection.
Downloads check free space, SHA-256 and GGUF architecture/tensor formats.
HDD streaming still needs RAM and does not enable every model. See MODEL_LIBRARY.txt.
