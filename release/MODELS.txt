All four small models are included. Qwen models are optional downloads.
For chat choose SmolLM2. For very limited story completion, try TinyStories
15M, or 260K for a minimal toy. Write Once upon a time, not a chat question.
260K often produces nonsense. 15M supports only 128 context tokens; 360AI
clamps the cache to this limit. These models are much less capable than chat
models. Use Auto/RAM, compute Auto and the Quick preset for short outputs.
The reserve column is for the extracted model, not extra RAM. To keep all
models, add their file sizes together and leave room for the app and logs.

DOWNLOAD OPTIONAL MODELS ON YOUR WINDOWS PC
Open PowerShell in this 360AI folder and run:
  powershell -ExecutionPolicy Bypass -File .\Download-Models.ps1 -List
  powershell -ExecutionPolicy Bypass -File .\Download-Models.ps1 -Model qwen25-05b
  powershell -ExecutionPolicy Bypass -File .\Download-Models.ps1 -Model qwen25-15b
  powershell -ExecutionPolicy Bypass -File .\Download-Models.ps1 -Model qwen25-7b

Downloads are pinned and checked against SHA-256 in models.json. The script
places files beside 360AI.xex. Copy the whole folder to your console HDD/USB.
Download only the models you want. Local inference needs no network or PC.

USE THE HDD FOR MODEL WEIGHTS
Launch the app from the folder containing the GGUF files. In Settings select
Weight storage: HDD/USB stream. Only an 8 MB weight cache is allocated; the
tokenizer, scratch buffers, small norm/bias tensors and KV cache stay in RAM.
Start at context 256-512. Larger contexts still need more real RAM.

Streaming reads model weights repeatedly. The 1.5B and especially 7B options
are experimental and can take a very long time per token. Their inclusion in
the catalog is not an Xbox benchmark or a performance guarantee. The HDD is
not general-purpose swap RAM. CPU/GPU math and attention still use RAM.

SPLIT MODELS
Keep every shard together with matching names. Select only the first shard.
The 7B download uses two files under 4 GB each and short console-friendly
names. The browser shows their combined storage requirement. Missing shards
cause loading to fail. GGUF shards are not ZIP or arbitrary file fragments.
