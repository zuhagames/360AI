# 360AI 2.6 - Find an answer faster

Find useful offline replies among the 150 starter answers with less controller typing.

- **Search:** press START in Starter answers, or type `find answers timer` / `search answers notes` in Assistant. Search matches whole words across questions, replies and categories, with exact questions ranked first.
- **Ask immediately:** click the right stick on a starter question to ask it in Assistant. B returns to the same result list, selection and search. Personal and file-based overrides follow normal chat priority.
- **Navigate results:** Y clears the filter; D-pad Left/Right pages filtered results in groups of six. Without a filter, Left/Right still jumps categories.
- **Keep personal tools:** My answers retains right-stick text preview, START undo, edit/delete confirmations and background saving. Starter customization uses the selected filtered result's actual phrase.
- **Debugging:** search is bounded to 96 bytes/16 distinct words. Invalid searches keep previous results, cancelled keyboards leave filters untouched, and empty results cannot ask or customize a different answer. Matching runs on query submission; clearing the search skips reply scanning.

All 150 starter replies and four bundled model weights remain included. This update improves browsing and instant-assistant use; GGUF generation speed is unchanged.

**Already on 2.1–2.5?** Open **START on Home → Updates** for the small app-only download. For a first installation or 2.0/older, extract **360AI-2.6-USB.zip** and copy its entire `360AI` folder to your drive. App-only updates preserve models, notes, personal answers, settings and custom rules.
