================================

- Direct Q4/Q5/Q8 CPU/VMX dot products; faster grouped Q4_K/Q5_K decoding.
- Assigned matrix workers to separate Xenon physical cores, replacing
  inherited single-hardware-thread execution and polling waits.
- Compute Auto compares real-weight CPU/GPU timing and numerical parity.
- Weight storage Auto chooses RAM when weights and working memory fit.
- Matching conversation prefixes reuse KV data instead of full reprocessing.
- Single-row disk reads no longer fetch the full 8 MB cache.
- Prompt progress, elapsed time, actual decode speed and performance logs.
- Console reply token limit is adjustable, default 128 (previously up to 512).

==========

- Faster top-k candidate selection and softmax limited to selected tokens.

- Warning-level logging by default to reduce per-layer USB log writes.
- Release packaging produces only the complete USB ZIP and prints its checksum.

  weights, pinned source/checksum, and required terms and notices.

- Experimental Xenos pixel-shader matrix calculations with CPU fallback.
- Tile-aligned R32F GPU resolve and untiled CPU readback; pixel-center sampling.
- GPU startup diagnostics include actual/expected values if validation fails.
- Corrected packed quantized-weight layouts and multi-block decoding.
- OpenAI-compatible completions/chat endpoints with streaming.
- Xbox insecure-LAN socket privilege and per-socket plaintext configuration.
- Health endpoint and local browser-client CORS/preflight support.
- MCP tools endpoint; optional PC bridge for external MCP servers.
- Original project credited to Canyons and contributors.

VALIDATION
Built and packaged with the Xbox 360 SDK. Native inference, weight
decoding, tokenizer, HTTP/MCP and executable privilege tests pass.
The bundled full GGUF also loads and generates text with the host build
of this engine. Source and archived model SHA-256 checksums are verified.
GPU performance and the corrected GPU path remain to be verified on

KNOWN LIMITS
MoE, Qwen3, vision/audio, arbitrary chat
templates and unsupported RoPE scaling are not implemented. Architecture
support does not mean every model fits console RAM. Consult the project
README for the detailed compatibility list.
