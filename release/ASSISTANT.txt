360 Assistant - native offline keyword and intent mode
======================================================

OPEN IT
Launch 360AI.xex and select Assistant on Home, even with no GGUF files present.
Press A to enter text. Say hello for a predefined reply, or type help.
Home X opens input directly; Home Y opens Quick tools. Notes and Timers have
their own controller screens. Xbox 360 button artwork is embedded in the XEX.
This mode runs inside the Xbox app with no model inference, website or PC.
It is a text assistant: microphone input, speech recognition and voice output
are not implemented. It matches supported intents, not arbitrary conversation.

PREDEFINED ANSWERS
150 starter answers are included in addition to the 106 existing phrase variants.
They cover getting started, notes, timers, personal answers, local models,
performance, the model library, updates, chat controls and everyday conversation.
Each of the ten categories has 15 distinct questions and written replies.
These are exact normalized question matches, with no model inference or actions.
Use the shown question; case and ordinary punctuation do not matter.

Open Saved answers and click the left stick for Starter/My answers.
D-pad Left/Right jumps categories; up/down selects a question. The right panel
shows the full question and reply. LB/RB reads long text; right stick previews.
A copies a starter reply into an editor. Saving uses one personal slot;
cancelling leaves everything unchanged. Existing personal overrides are edited
in place. Y in Starter view opens My answers; Y there confirms deletion.
Removing an override exposes the original starter again. All 150 starters
remain available even when the 16 personal slots are full. No starter is written
over your personal data or counted against those slots. A fresh empty notebook
opens Starter view by default; existing personal answers are kept as-is.

106 exact phrase variants cover greetings, thanks, everyday conversation and
common questions. Examples: hello, good morning, how are you, i am bored,
and what do you think about the xbox 360. Matching ignores case and ordinary
punctuation. It uses a small index built once, with no model inference. Saved
taught/file answers can customize a matching reply; built-in actions retain
priority. A phrase inside an unrelated sentence does not trigger an action.

CONTROLLER SCREENS
Home: D-pad selects Assistant, Notes, Timers or Models. A opens the selection.
Quick tools: calculations, conversions, new timer/note, Saved answers and help.
Notes: up/down select, A edits, X adds, Y asks to delete, START undoes.
LB/RB pages through a long note. Typed note content is saved literally.
Timers: up/down select, A pauses/resumes, X adds, Y asks to cancel.
RB adds a minute; LB restarts. B returns Home. Confirmations use A/B.
Returning Home cancels a waiting chat follow-up or confirmation. Chat text
and saved data are kept; an old yes/no question cannot execute after reopening.

CALCULATOR
  calculate (12 + 8) * 3
  what is 20 percent of 80
  calculate sqrt(81) + abs(-5)
  calculate 2^8
  calculate ans / 2
  what's twenty-five plus one hundred and five
Precedence, parentheses, unary minus, right-associative powers, round, pi and
e are supported. ans is the last successful answer. % means remainder.
Division by zero, invalid syntax, overflow and overly complex input fail
without changing ans. Expressions are bounded to 256 characters.
English numbers through thousands and decimal digit words are accepted,
such as two point five times four. This is bounded parsing, not general NLP.

UNIT CONVERSIONS
  convert 5 miles to km
  and 10
  what is 32 F in C
  convert 2 kg to lb
  convert 1 MiB to bytes
Length, mass, temperature, time and byte storage are supported. Follow-up
and 10 reuses the last successful unit pair. MB/GB use decimal bytes;
MiB/GiB use binary bytes. Currency and live exchange rates are unavailable.

TIMERS AND RELATIVE REMINDERS
  set timer 5 minutes called pizza
  set timer 1h30m
  remind me in 10 minutes to check the oven
  remind me to stretch
  (then answer 5 minutes)
  list timers
  cancel timer 1
  pause timer pizza
  resume it
  extend timer pizza by thirty seconds
  restart timer pizza
  check timer pizza
  cancel all timers
  timer history
Up to eight timers, 1 second to 7 days, run while 360AI remains open. Half an
hour, twenty five minutes and compound durations are understood. Completion shows
a ten-second banner on app screens and records a chat alert. Timer history
keeps the last eight alerts for this session. Timers/history do not survive
closing or restarting the app. There is no system alarm or audio alert.
Pause freezes the remaining time; resume continues it. Restart uses the
original duration plus any extensions. Extensions keep the total within
seven days. Commands accept an exact timer number or label; duplicate labels
ask for a number. It refers to the most recently created/selected timer in
this chat and is cleared when that timer is cancelled or completes. Expired
timers cannot be restarted. Paused timers count toward the eight-timer limit.

NOTES AND NAME
  remember to buy batteries
  remember
  (then enter the note)
  list notes
  read note 1
  find notes about batteries
  edit note 1: buy rechargeable batteries
  edit note 1
  (then enter replacement text)
  delete note 1
  delete all notes
  undo
  my name is Martin
  what is my name
  forget my name
Up to 32 notes (512 bytes each) and a name (64 bytes) save as plain text in
360AI-assistant.json beside the app, with a previous valid .bak recovery copy.
The drive must be writable. A single background worker saves the latest
bounded snapshot. Saving/Saved/Not saved is shown; wait for Saved before
closing after an edit. Failures retain in-memory data and can be retried by
another command. Older completions cannot mark newer edits as saved. Updates
do not include or overwrite these personal files.
Deleting one note requires its exact number. Deleting all notes and clearing
chat ask yes/no; a different request cancels the pending operation.
Search matches all supplied whole words in any order. Read/edit/delete
require an exact note number. Note IDs are not reused after deletion or undo,
including after restarting with the new save format. Version 1 saves migrate
automatically. Invalid saved text/control characters are rejected before
changing memory; backup recovery is attempted when the main file is invalid.

TEACH ANSWERS ON YOUR XBOX
Open Home > Y Quick tools > Saved answers, or type open saved answers.
Up/down: select. A: edit the reply. X: new phrase, then new reply.
Y: confirm deletion. START: undo the latest saved-data change.
LB/RB: read a long reply. Click right stick: test a saved-text match.
B cancels a keyboard or deletion; B on the main screen returns to Tools.
New drafts do not change saved data until both fields are valid. Cancelling
either keyboard keeps existing answers. Duplicate phrases select the existing
entry and ask you to edit it, rather than replacing its reply silently.
Previews show the longest saved phrase matching whole words in your input.
They never run commands or alter saved data. In Starter view, preview also
checks exact starter questions after personal matches. File FAQ rules are
not part of preview; actual chat still applies its normal answer priority.
Chat still gives built-in commands priority. An answer saying delete all notes
is only text. Editing and deletion use the same background save and undo path
as typed teaching. Existing taught answers appear without a migration.

  teach favorite game: Halo 3
  what is your favorite game
  list learned answers
  forget answer favorite game
  undo
Up to 16 phrase/answer pairs are saved in 360AI-assistant.json with your notes
and name. Phrases use 3-80 bytes after normalization; answers use 1-512 bytes.
Teaching the same normalized phrase replaces its answer. Forget requires
that exact phrase. Whole-phrase matches win by length; a taught answer wins
ties with file-based/built-in FAQ answers. Built-in commands keep priority.
Ordinary phrases such as answer to life, half life and one question are not
mistaken for calculator inputs. Explicit calculate commands still take priority.
Answers are text only: even an answer saying clear chat cannot run a command.
This is explicit saved knowledge, not neural training or arbitrary reasoning.

UNDO
Undo restores the last change to notes, your name or taught answers, including
confirmed bulk note deletion. It is one level, kept for this app session only.
Unsuccessful commands and read-only questions leave it available. Undo does
not affect timers, presets, transcript export or cleared chat. Undo itself
cannot be undone. The restored data is saved through the normal save path.

XBOX APP COMMANDS AND HELP
  status | time | date | list models
  quick preset | balanced preset | creative preset
  help with GPU | help with memory | help with MCP | help with controls
  joke | another joke
  export chat | clear chat | open models
Presets change saved GGUF settings. They do not change keyword answers.
Clock/date use the console's configured clock. No current weather, news,
internet searches or prices are provided. Unknown questions receive a clear
fallback. Spelling suggestions never automatically execute a command.

FOLLOW-UPS AND CONTROLS
Use cancel or never mind to leave a follow-up. A recognized new command
replaces it. Polite prefixes, case differences and normal spacing are handled.
Common sentence punctuation works after timer/note numbers. An oversized
request or an empty message cancels a waiting follow-up/confirmation.
Read-only commands such as status?, notes and timer history interrupt note,
name, calculation and timer prompts without becoming saved text or a label.
Use explicit edit note 1: status? to save command-like text as note content.
Timer labels keep words such as the, my and timer; punctuation-only labels
are rejected. Use an ID for a label that is also a command or the Timer keyword.
Use one command per message. Negated commands do not execute; don't forget
to is treated as a request to save a note. Timer alerts still work after
returning to models or switching to a GGUF while this app remains open.

A: input. D-pad: scroll. LB/RB: page. Right-stick: latest. X: new chat.
Y: Quick tools. START: save transcript to 360AI-chat.txt. B: Home.
New/cleared chat resets dialog, ans, conversion follow-ups and the it timer
reference. It keeps saved data, undo and session timers. Scrollback is bounded.

CUSTOM ANSWERS
Copy assistant-rules.example.json to assistant-rules.json to add custom
answers, then edit that copy and restart. Updates include only the example,
preserving your custom file. The example is used when no valid custom file
is available. Optional assistant-rules.json contains version 1 and a rules array. Each rule
has phrases (1-8 strings, up to 80 bytes each) and response (up to 2000 bytes).
Up to 64 rules in a 64 KiB file are accepted. Entire phrases match at word
boundaries; the longest match wins. Equal-length custom answers take priority
over built-in FAQ entries. Taught answers win ties with file answers;
built-in actions take priority over all FAQ rules.
Rules return text only, with no scripts, shell commands or networking.
Restart after editing. An invalid file is ignored; built-in commands remain.

VALIDATION
Native tests exercise arithmetic errors/precedence, conversion dimensions,
follow-up slots, word boundaries, typo suggestions, negation, interrupted
confirmations, timer expiry/pause/resume/restart/extension/ambiguity, note
search/edit/undo, learned-answer limits, save migration/stable IDs, corrupt
data and backup recovery. A deterministic 2,000-case malformed-input pass
checks bounded failure without app actions. Additional regressions cover
78 prompt/command interruption pairs, literal timer labels, taught phrases
that resemble math, and multiline note save/undo round-trips. JSON uses compact
standard control escapes so valid saved notes stay within the file-size bound.
Xbox SDK compilation is checked. Physical-console
menus, keyboard behavior, timer banner and storage persistence still need
hardware validation. No Siri-equivalent language or speech ability is claimed.
